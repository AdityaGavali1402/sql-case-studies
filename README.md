# SQL Case Studies: Healthcare, Finance, E-Commerce, HR and Retail

Five end-to-end SQL case studies, one for each business domain. Each case study creates a 1,000-row dataset, answers 10 business questions with MySQL, and explains what each result means.

## Case Studies

| Domain | Business Focus | SQL Concepts | Link |
|---|---|---|---|
| E-Commerce | Order value, category volume, city demand | `WHERE`, `IN`, `GROUP BY`, `HAVING` | [View](ecommerce/) |
| Finance / Banking | Transaction amounts, account types, investments | `WHERE`, `IN`, `SUM`, `HAVING` | [View](finance/) |
| Healthcare | Patient cost, disease burden, high-cost cases | `WHERE`, `AND/OR`, `GROUP BY`, `HAVING` | [View](healthcare/) |
| HR Analytics | Salary levels, departments, experience | `AVG`, `GROUP BY`, `HAVING`, `ORDER BY` | [View](hr-analytics/) |
| Retail | Product pricing, category sales, store spread | `SUM`, `GROUP BY`, `HAVING`, `LIMIT` | [View](retail/) |

## What Each Case Study Contains

- Business problem and table structure
- 10 questions, from basic filtering to grouped aggregation
- The SQL query, a sample of its output, and a one-line business insight
- Key takeaways

## Skills Covered

- Filtering: `WHERE`, `AND`, `OR`, `IN`
- Sorting and limiting: `ORDER BY`, `LIMIT`
- Aggregation: `SUM`, `AVG`, `MAX`, `MIN`
- Grouping: `GROUP BY`, `HAVING`
- Column aliases and readable query formatting
- Recursive CTE to generate 1,000 rows of test data

## Tools

MySQL 8, MySQL Workbench, Git and GitHub

## How to Run

1. Open any domain folder and download its `.sql` file.
2. Run the whole file in MySQL Workbench. It creates the database, generates 1,000 rows and runs all the queries.
